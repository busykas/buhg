## 1.Ключевая идея

Калькулятор на Python выполняет точные вычисления с целыми числами, обыкновенными и десятичными дробями. Он поддерживает сложение, вычитание, умножение, деление, извлечение квадратного корня и возведение в степень. И основание, и показатель степени могут быть дробными.

Калькулятор не округляет результаты: рациональные числа выводятся в виде целого числа или сокращённой дроби, а иррациональные — в виде точного выражения с корнем.

Например, `1/3 + 0,25` даёт `7/12`, `8/27 ^ 2/3` даёт `4/9`, а `sqrt 2` выводится как `√(2)`.
